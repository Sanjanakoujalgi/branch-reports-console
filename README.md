# AHG monthly operations dashboard

Open the site, click **Upload files** and pick the month's Excel files (POS Daily Operations, Purchase Order, Stock On Hand). Everything is worked out in the browser: the files are not sent anywhere.

Tabs: Overview, Sales, Menu, Purchases, Suppliers & prices, Stock, Compare months, Data quality. Downloads: Report tables (Excel), Cleaned data, Power BI data, the whole dashboard as PDF, one tab as PDF.
